# 1. Login Flow

Goal

Allow authenticated users to securely access Atlas.

Flow

Open Atlas
      ↓
Enter Email
      ↓
Enter Password
      ↓
Click Login
      ↓
Credentials Valid?
      ↓
Yes → Dashboard

No → Error Message
